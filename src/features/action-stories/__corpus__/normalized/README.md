# Normalized Decision Objects — the canonical dataset

Generated by `npm run normalize` (`extraction/normalizeCorpus.js`) from the archived corpus in
`../fixtures/raw/`. Deterministic: the same corpus produces byte-identical output.

## What is here

| Path | Purpose | Loaded at runtime? |
|---|---|:--:|
| `dataset.json` | All 105 Decision Objects in one bundle | **Yes** — by `src/services/mockDecisionApi.js` |
| `proposals/*.json` | One file per Decision Object, 105 files | No — evidence, and the natural upload unit for a real API |
| `examples/*.json` | One representative per template family, 5 files | No — for contract review |

`dataset.json` is a single bundle rather than a directory glob on purpose: `import.meta.glob` over
story data is precisely the runtime coupling this work removes.

## What this is, and is not

**Is:** clean business data. 26 Action Stories × their stages. No CSS variables, no pixel geometry,
no SVG path strings, no React props/state, no `__raw`, no UI visibility flags, no component names or
layout instructions. Numbers are typed `{value, unit}`. Guardrails use the 4-value verdict enum.
Every record validates against `contract/decisionObject.js`.

**Is not:** production business truth. Several contract fields have no source in the corpus and are
synthesised deterministically — see the UNRESOLVED list in
[`docs/DECISION_OBJECT_DATA_AUDIT.md`](../../../../../docs/DECISION_OBJECT_DATA_AUDIT.md). In
particular `action_type`, `contract_class`, `entitlement`, `on_clock`/`deadline`, `impact`, `status`
and `updated_at` are placeholders awaiting a product decision. They are labelled as such in the
generator and must not be mistaken for derived facts.

## Relationship to the raw corpus

`../fixtures/raw/` and `../manifests/` are **reference evidence only**. They are never loaded at
runtime, are not deleted, and remain the record of where every normalized value came from. A test
(`normalizedDataset.test.js`) asserts that no runtime module imports them.

## Regenerating

```bash
npm run normalize     # rewrite this directory from the corpus
npm run audit:data    # regenerate docs/DECISION_OBJECT_DATA_AUDIT.md
npm test              # 30 assertions guard the dataset's shape and hygiene
```
