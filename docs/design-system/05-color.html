03 COLOR SYSTEM

Graphite anchored. Meaning earned.

Realify Graphite carries the brand. Every other colour has a job: green reports health, amber warns, rose alerts, violet marks intelligence, and a warm neutral ink carries the page. No decorative colour survives. If a hue doesn't describe a state, it doesn't ship.

Contrast matrix

Every brand colour tested against both white and ink-900 surfaces. AA passes at 4.5:1 for normal text and 3:1 for large text or UI controls; AAA passes at 7:1. Colours marked "Large only" may be used for headings, icons, or decorative accents — never for body copy.

Gradient system

Realify uses gradients sparingly — never decoratively. They mark atmosphere, depth, or continuity (sparklines, glow, diurnal context). Flat colour remains the default; a gradient must earn its appearance.

Pairing rules

The short answer: ink on ink, blue on white, accent colours only on neutral surfaces. Never set brand blue on a coloured surface; never set a semantic colour on another semantic colour.

DO Ink 900 CTA on white
DON'T Ink 900 on blue — muddy, low contrast
